Privacidade

Versão beta · atualização: 31/08/2026

O RUMO está em fase beta. Esta página explica, em linguagem simples, quais dados a plataforma usa para funcionar. Antes de um lançamento comercial amplo, este texto deve passar por revisão jurídica adequada à operação real.

Quais dados usamos

Quando você cria uma conta, podemos armazenar e-mail, nome de exibição, objetivo de estudo, concurso, rotina, progresso, sessões de estudo, questões e erros registrados por você. Esses dados são usados para personalizar o plano e mostrar seu próprio histórico.

Editais em PDF

Na versão atual, a leitura do edital é feita no navegador. O RUMO extrai o texto localmente para identificar matérias e tópicos; o arquivo PDF em si não é enviado para armazenamento pela funcionalidade de importação local.

Onde os dados ficam

Os dados de conta e progresso são armazenados em infraestrutura Supabase. A aplicação é hospedada na Vercel durante a fase beta. Cada usuário autenticado possui regras de acesso no banco para limitar a leitura e alteração aos próprios registros.

Links externos

O RUMO pode indicar buscas no YouTube ou na web. Ao abrir esses serviços, passam a valer as políticas de privacidade das plataformas externas.

Seus controles

Você pode sair da conta a qualquer momento. Recursos de correção, exclusão e exportação completa de dados serão formalizados antes do lançamento comercial.

EDEN

RUMO é um produto desenvolvido sob a marca EDEN. O projeto técnico é organizado como EDEN RUMO.
